# تغذیه‌یار خانواده

یک MVP وب RTL و local-first برای مدیریت تغذیه خانواده؛ با تمرکز بر این اصل که «یک غذا، چند نفر، سهم متفاوت».

## امکانات نسخه اول

- داشبورد خانوادگی با ثبت‌های روزانه، پیوستگی و بینش ساده
- مدیریت اعضای خانواده و پروفایل تغذیه‌ای
- برنامه غذایی هفتگی با غذاهای ایرانی و امکان پیشنهاد هوشمند
- ثبت سریع غذا، تنقلات و نوشیدنی برای چند عضو
- گزارش روند وعده‌ها و گروه‌های غذایی
- ذخیره‌سازی local-first در `localStorage` برای استفاده آفلاین از داده‌های پایه
- طراحی کامل RTL و واکنش‌گرا برای موبایل و دسکتاپ

## اجرا

```bash
npm install
npm run dev
```

این پروژه عمداً لایه داده و قابلیت‌های آنلاین را جدا نگه می‌دارد تا در مرحله بعد بتوان Repository/Service برای AI، همگام‌سازی ابری، OCR و Health Connect اضافه کرد.

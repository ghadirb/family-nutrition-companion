# تغذیه‌یار خانواده

یک MVP وب RTL و local-first برای مدیریت تغذیه خانواده؛ با تمرکز بر این اصل که «یک غذا، چند نفر، سهم متفاوت».

## امکانات نسخه اول

- ساخت و ویرایش خانواده و مدیریت اعضا با اطلاعات پایه، قد، وزن، فعالیت، هدف، ترجیحات و محدودیت‌ها
- پروفایل تغذیه‌ای هر عضو با امکان ویرایش و حذف
- برنامه غذایی هفتگی قابل ویرایش، حذف وعده و افزودن وعده سفارشی
- ثبت سریع غذا، تنقلات و نوشیدنی برای چند عضو با ساعت، مقدار و وضعیت «خورد/نخورد»
- گزارش‌های محاسباتی از روی ثبت‌های واقعی، بدون اعداد ساختگی ثابت
- بانک اولیه غذای ایرانی با جستجوی فارسی و نرمال‌سازی «قورمه/قرمه»
- Backup واقعی JSON برای Export/Import و بازیابی روی دستگاه دیگر
- وضعیت حساب رایگان/Premium با گیت‌کیپینگ پایه
- ذخیره‌سازی local-first در `localStorage` برای استفاده آفلاین از داده‌های پایه
- دستیار AI متصل به داده‌های خانواده؛ پرسش‌های معمولی با مدل اقتصادی و پرسش‌های دارای نیاز به اطلاعات تازه با Sonar
- پروکسی امن سمت سرور برای AvalAI تا کلید API هرگز به مرورگر یا GitHub ارسال نشود
- لیست خرید گروه‌بندی‌شده با تیک خرید، حذف و افزودن مورد
- موجودی خانه با مقدار، دسته‌بندی و هشدار مواد نزدیک انقضا
- مرکز اعلان‌های قابل خاموش‌کردن و درخواست اجازه مرورگر
- ثبت صوتی مبتنی بر Web Speech API و انتخاب عکس غذا با تأیید کاربر
- چاپ گزارش برای ذخیره PDF و کارت آماده اتصال اختیاری Health Connect
- طراحی کامل RTL و واکنش‌گرا برای موبایل و دسکتاپ

## اجرا

```bash
npm install
npm run dev
```

برای اجرای نسخه production همراه با دستیار AI:

```bash
Copy-Item .env.example .env
# مقدار AVALAI_API_KEY را در .env قرار دهید
npm install
npm run build
npm start
```

برای توسعه، سرور AI را با `npm start` و رابط Vite را در یک ترمینال جدا با `npm run dev` اجرا کنید.

مدل پیش‌فرض پرسش‌های عادی `gpt-5.4-mini` و مدل پرسش‌های نیازمند جستجوی وب `sonar` است. اگر Sonar موقتاً در دسترس نباشد، برنامه با برچسب شفاف به مدل اقتصادی fallback می‌کند و ادعای تازه بدون منبع را قطعی نشان نمی‌دهد.

این پروژه عمداً لایه داده و قابلیت‌های آنلاین را جدا نگه می‌دارد تا در مرحله بعد بتوان Repository/Service برای AI، همگام‌سازی ابری، OCR و Health Connect اضافه کرد.
